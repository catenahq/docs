## Cloudflare API operations

The operator's controller makes these calls to your CF account
during `./catena site`. Token is kept local; never on the VPS.


### `infrastructure/`

- CF DNS: create wildcard CNAME if absent
- CF DNS: look up existing wildcard record
- CF DNS: update wildcard CNAME if content drifted
- CF: enforce tunnel ingress (wildcard → Traefik)
- CF: fetch tunnel token
- CF: list existing tunnels with this name
- CF: look up zone_id for {{ cloudflare_zone }}
- CF: probe full chain (edge → tunnel → Traefik)
- Create tunnel if it doesn't exist

## Caveats

This list is heuristic. The script greps templates and tasks;
anything dynamic (computed at runtime) or indirect (called via
a downstream script) may be missed. When in doubt, `grep -r`
the roles tree with the operator.
